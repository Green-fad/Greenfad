## 🛠️ Technologies Utilisées

### Frontend
- **HTML5** : Structure sémantique moderne
- **CSS3** : Variables CSS, Flexbox, Grid, animations
- **JavaScript (ES6+)** : Classes, modules, API modernes
- **Font Awesome 6** : Icônes vectorielles
- **Google Fonts (Inter)** : Typographie professionnelle

### Fonctionnalités JavaScript
- **Navigation Class** : Gestion du menu et scroll
- **FormHandler Class** : Validation et soumission de formulaire
- **ScrollAnimations Class** : Animations au scroll avec Intersection Observer
- **BackToTop Class** : Bouton retour en haut
- **LazyLoader Class** : Chargement différé des images
- **AccessibilityEnhancements Class** : Améliorations d'accessibilité
- **PerformanceMonitor Class** : Monitoring des performances (dev)

### Design System
- **Variables CSS** : Couleurs, espacements, typographie
- **Breakpoints** : Mobile, Tablet, Desktop
- **Color Palette** : 
  - Primary: #00D4AA (Vert Greenfad)
  - Secondary: #6C5CE7 (Violet)
  - Accent: #FDCB6E (Jaune)
- **Typography Scale** : 10 tailles de police
- **Spacing Scale** : 12 valeurs d'espacement
- **Shadows** : 6 niveaux d'ombre

## 🚀 Installation & Développement

### Prérequis
- Navigateur web moderne (Chrome, Firefox, Safari, Edge)
- Serveur local (optionnel pour le développement)

### Installation

```bash
# Cloner le repository
git clone https://github.com/Green-fad/Greenfad.git

# Naviguer dans le dossier
cd Greenfad

# Ouvrir avec un serveur local (optionnel)
# Option 1: Python
python -m http.server 8000

# Option 2: Node.js
npx serve .

# Option 3: PHP
php -S localhost:8000
```

### Développement Local

```bash
# Avec Live Server (VS Code)
# Installer l'extension Live Server
# Clic droit sur index.html > "Open with Live Server"

# Avec Python
python3 -m http.server 8000

# Avec Node.js
npx http-server . -p 8000
```

Ouvrir [http://localhost:8000](http://localhost:8000) dans votre navigateur.

## 🎨 Personnalisation

### Modifier les Couleurs

Éditez les variables CSS dans `assets/css/styles.css` :

```css
:root {
    --greenfad-primary: #00D4AA;
    --greenfad-secondary: #6C5CE7;
    --greenfad-accent: #FDCB6E;
    /* Modifiez selon vos besoins */
}
```

### Modifier le Contenu

Le contenu principal se trouve dans `index.html`. Sections facilement identifiables avec des commentaires.

### Ajouter des Animations

Utilisez les classes d'animation existantes ou créez-en de nouvelles dans `styles.css`.

## 🌐 Déploiement

### GitHub Pages
Le site est automatiquement déployé sur GitHub Pages à chaque push sur la branche `main`.

**URL de production** : [https://green-fad.github.io/Greenfad/](https://green-fad.github.io/Greenfad/)

### Configuration GitHub Pages
1. Allez dans **Settings** > **Pages**
2. Source : **Deploy from a branch**
3. Branch : **main** / **root**
4. Save

### Autres Plateformes

#### Netlify
```bash
# Déployer sur Netlify
netlify deploy --prod
```

#### Vercel
```bash
# Déployer sur Vercel
vercel --prod
```

#### Firebase Hosting
```bash
# Déployer sur Firebase
firebase deploy
```
